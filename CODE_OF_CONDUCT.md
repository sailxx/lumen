# Code of conduct

We want Lumen's community to be welcoming and useful to everyone.

- Be respectful and constructive in issues, reviews, and discussions.
- Critique ideas and code without attacking people.
- Do not harass or discriminate against other contributors.
- Share diagnostic information carefully and remove personal data when appropriate.

Maintainers may remove content or restrict participation when these
standards are not followed. Report conduct concerns privately to the
repository maintainers.
