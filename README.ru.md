# Lumen

**Управление яркостью каждого дисплея в GNOME Shell.** Настраивайте яркость встроенного экрана ноутбука и внешних мониторов DDC/CI из меню верхней панели.

## Возможности

- Для каждого подключённого экрана отображается собственный ползунок яркости. Для встроенного дисплея Lumen использует системную подсветку через logind, а для внешних мониторов — `ddcutil` и DDC/CI. Программа читает значение с самого дисплея и показывает его как недоступное, если получить его нельзя.
- Прокручивайте строку дисплея, чтобы менять его яркость. Прокрутка по значку на панели управляет последним выбранным дисплеем. Шаг настраивается от 1% до 25% (по умолчанию 5%); команды кратко объединяются, чтобы не отправлять их при каждом движении колеса.
- При открытии меню Lumen обновляет значения. Также можно повторно обнаружить дисплеи после подключения или отключения экрана кнопкой **Обновить дисплеи**.
- Lumen работает как расширение GNOME Shell, не запускает фоновую службу и не подключается к сети. Для внешних мониторов может потребоваться однократная настройка `ddcutil`, модуля `i2c-dev` и прав доступа к устройствам в активном сеансе. При изменении яркости служба с правами root не нужна.

## Установка

### Настройка Linux

Скрипт настройки поддерживает Fedora (`dnf`), Debian/Ubuntu (`apt-get`), Arch Linux (`pacman`) и openSUSE (`zypper`). Он устанавливает `ddcutil` и `i2c-tools`, включает `i2c-dev` и, если в системе нет подходящего правила udev для ddcutil, настраивает доступ к устройствам I2C в активном сеансе. Перед запуском проверьте содержимое скрипта.

```bash
git clone https://github.com/sailxx/lumen.git
cd lumen
./setup-monitor-brightness.sh
```

Выйдите из системы и войдите снова, чтобы применились права на устройства. Затем из сеанса GNOME установите архив расширения:

```bash
sudo dnf install zip glib2-devel   # Fedora, если не хватает инструментов сборки
cd extension
./install.sh
```

Перезапустите GNOME Shell и включите Lumen:

```bash
gnome-extensions enable lumen@vlad
```

В Wayland выйдите из системы и войдите снова. В X11 нажмите `Alt`+`F2`, введите `r` и нажмите Enter.

### RPM для Fedora

```bash
sudo dnf install rpm-build
git clone https://github.com/sailxx/lumen.git
cd lumen/rpm
./build-rpm.sh
sudo dnf install rpmbuild/RPMS/noarch/gnome-shell-extension-lumen-*.rpm
gnome-extensions enable lumen@vlad
```

RPM устанавливает расширение и схему настроек в систему, добавляет правило udev и включает загрузку `i2c-dev` при запуске. После установки перезапустите GNOME Shell.

## Требования и известные ограничения

- Linux с GNOME Shell 45–50.
- `ddcutil` версии 1.4 или новее и `i2c-tools` для внешних мониторов.
- Монитор с поддержкой DDC/CI, где DDC/CI включён в экранном меню.
- `zip` и `glib-compile-schemas` для сборки локального архива расширения.
- Для встроенной подсветки нужен интерфейс в `/sys/class/backlight` и разрешение logind для текущего сеанса.

Некоторые док-станции и переходники ненадёжно передают DDC/CI. В отдельных конфигурациях драйвера NVIDIA может потребоваться `nvidia-drm.modeset=1`; ориентируйтесь на инструкции своего дистрибутива.

| Проблема | Что проверить |
|---|---|
| Внешний дисплей не найден | Включите DDC/CI в меню монитора, запустите `ddcutil detect`, затем выберите **Обновить дисплеи**. |
| `ddcutil` сообщает об отказе в доступе | После настройки выйдите из системы и войдите снова, чтобы применились права активного сеанса. |
| Ползунок недоступен | Проверьте DDC/CI и выполните `ddcutil getvcp 10`, чтобы узнать, сообщает ли монитор яркость. |
| Монитор подключён через док-станцию | Переподключите его и выполните поиск ещё раз: некоторые док-станции не передают DDC/CI. |

Полезные команды диагностики:

```bash
ddcutil environment
ddcutil detect
journalctl --user -b _COMM=gnome-shell | grep -i lumen
```

## Использование и удаление

Откройте значок солнца в верхней панели GNOME и переместите ползунок нужного дисплея. Прокрутка строки меняет яркость этого дисплея, а прокрутка по значку на панели — яркость последнего выбранного. В разделе **Настройки** можно скрыть встроенный экран и изменить шаг прокрутки.

Удаление RPM:

```bash
sudo dnf remove gnome-shell-extension-lumen
```

Удаление расширения, установленного из архива:

```bash
gnome-extensions disable lumen@vlad
rm -rf ~/.local/share/gnome-shell/extensions/lumen@vlad
```

Если настройка создала `/etc/modules-load.d/lumen-i2c-dev.conf` или `/etc/udev/rules.d/60-monitor-brightness-i2c.rules`, удалите эти файлы, чтобы отменить соответствующую настройку системы, затем перезагрузите правила udev.
